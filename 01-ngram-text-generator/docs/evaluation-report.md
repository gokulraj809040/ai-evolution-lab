# Model Evaluation & Benchmark Report

*(This report will be populated during Phase 6 with empirical measurements from held-out test datasets).*

## Metrics to Measure
1. **Top-1 Next-Token Accuracy:** Percentage of test tokens correctly predicted as top candidate.
2. **Unknown-Context Rate:** Frequency of encountering contexts not seen in training.
3. **Repetition Rate:** Ratio of repeated N-grams in generated text.
4. **Vocabulary Diversity:** Ratio of unique generated tokens to total generated tokens.
