The Core Functions You'll Understand By The End

The statistical language model pipeline mapped to fundamental GenAI concepts:

Engine Function Main GenAI Concept Role in the Autoregressive Pipeline
normalizeText() Preprocessing Standardizes case, trims whitespace, handles punctuation rules
tokenize() Tokenization Converts raw string sequences into discrete mathematical tokens
extractNgrams() Context-window construction Extracts sliding window $(N-1)$ context tuples and target tokens
trainModel() Statistical training Accumulates sequence frequencies into nested Map distribution tables
extractContext() Context selection Extracts the last $(N-1)$ prompt tokens for candidate conditioning
lookupCandidates() Model inference Queries the statistical model for continuations given current context
calculateProbabilities() Probability distributions Normalizes raw counts into conditional probabilities: $P(w_i \mid w_{i-N+1}^{i-1})$
decodeGreedy() / decode() Next-token selection Selects token via Greedy argmax, Temperature scaling, Top-K, or Top-P
predictNext() Prediction pipeline Coordinates context lookup, probability distribution, and candidate ranking
generateText() Autoregressive generation Iterative generation loop updating context until EOS or max tokens
evaluateModel() Model evaluation Measures top-1 accuracy, perplexity, and unknown-context rate on held-out test data
